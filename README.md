# ФЕРРОФРОНТ — мобильная локационная стратегия про войну роботов

Превращает реальный город в персистентное поле боя: игрок исследует районы пешком,
захватывает территории, управляет заводами, собирает модульных боевых мехов,
строит базу и воюет за сектор с фракциями (ИИ-соперники) и живыми игроками (P2P).

**Статус:** играбельный MVP полного основного цикла. Стек: React 18 + TypeScript +
Vite + Tailwind 4, игровой рендер — Canvas 2D, состояние — reducer + localStorage.

---

## Быстрый старт

```bash
npm install
npm run dev        # локальная разработка
npm run build      # прод-сборка в dist/
npm run preview    # проверить сборку
```

Открывать лучше с телефона в одной сети (или `npm run dev -- --host`) —
тогда работают GPS, акселерометр и компас.

## Как устроен мультиплеер БЕЗ своего сервера

Три слоя, включены первые два:

### 1. Асинхронный «фантомный» мультиплеер (встроен)
Мир никогда не пуст: три ИИ-фракции живут как игроки — захватывают соседние зоны,
рейдают ваши территории (с защитными механиками), пишут в канал альянса, участвуют
в рейтингах. Одиночная игра ощущается как многопользовательская.

### 2. Реальный P2P через WebRTC (встроен, экран «Альянс → P2P-комната»)
- `RTCPeerConnection` + `RTCDataChannel`, **ноль зависимостей, ноль своего сервера**.
- Сигнализация — ручная (vanilla ICE): хост создаёт комнату и получает
  **код-приглашение** (SDP+ICE в base64), передаёт его второму игроку любым
  мессенджером; тот возвращает **код-ответ**. Как LAN-режим в консольных играх.
- STUN — публичные серверы Google, NAT-пробитие для большинства сетей.
- Топология «звезда»: хост ретранслирует события гостям (host-authoritative).
- Синхронизируются: **захваты зон** (владелец меняется у всех участников),
  **чат**, присутствие (список игроков в комнате).

### 3. Путь к продакшену (документация, интерфейс готов)
Интерфейс `NetClient` изолирован от игры: ручная сигнализация заменяется на
автоматическую без переписывания геймплея. Варианты по возрастанию затрат:
1. **PeerJS Cloud** — бесплатный публичный брокер, комнаты по коротким ID.
2. **Supabase Realtime / Firebase RTDB** — presence + события + серверная БД мира
   (общая карта для всех, персистентные территории, античит на сервере).
3. **Colyseus / собственный WebSocket-сервер** — авторитативный сервер, матчинг,
   кланы, сезонные сбросы.

> Почему не «сразу сервер»? MVP обязан запускаться со статического хостинга
> (GitHub Pages / Netlify / Vercel) без инфраструктуры и ключей. P2P даёт
> настоящий live-геймплей уже сейчас, а архитектура не блокирует переход.

## Датчики телефона

| Датчик | Использование | Деградация |
|---|---|---|
| GPS (`watchPosition`) | реальные координаты → позиция в секторе (якорная привязка), точность показывается в чипе | режим симуляции: джойстик |
| Акселерометр (`devicemotion`) | детекция шагов (пик-детектор, рефрактор 320 мс) → шаги, энергия развёртывания, задания | не считается |
| Компас (`deviceorientation` / `webkitCompassHeading`) | курс маркера, пеленг-стрелка к выбранной зоне с дистанцией | пеленг от севера карты |

iOS требует явный жест пользователя для доступа к движению/компасу —
кнопка **«ВКЛЮЧИТЬ ДАТЧИКИ»** в панели датчиков на карте (иконка радара).
Отказы и «датчика нет» обрабатываются явными статусами, игра не ломается.

## Игровые системы (краткий дизайн-док)

**Основной цикл:** разведка пешком → захват зоны боем → доход и заводы →
производство модулей → сборка мехов → более сильные цели → база и исследования →
события и война фракций.

- **Территории:** гекс-сетка, 11 типов (районы, ресурсные узлы, заводы, форты,
  достопримечательности, парки, вода). Туман разведки, кулдаун повторного штурма 90 с,
  укрепление гарнизонов, бонусы связной сети (3/5/10 зон → +5/10/15% дохода).
- **Бой:** реальное время, до 3 мехов, поведения (агрессивный/оборона/поддержка/
  по структурам/дальний бой), укрытия с прострелом, фокус огня, способности,
  отход, скорость ×1–×4, AR-режим поверх камеры (опционально). 60–180 секунд.
- **Мехи:** 6 слотов, 25 модулей, честные трейд-офы (масса/грузоподъёмность,
  энергобаланс режет темп огня), архетипы emergent, жёстких классов нет.
- **Экономика:** 6 ресурсов + кредиты; доход территорий с лимитом склада;
  энергия развёртывания (25 за бой, регенерация временем и ходьбой) — мягкий
  ограничитель темпа, не стена.
- **Прогрессия:** уровень командира, инженерный уровень, дерево исследований
  (5 веток, разблокирует возможности, а не только цифры), 7 рангов, достижения.
- **Задания:** 5 ежедневных (ротация), 6 недельных, операция «Первый рубеж»
  (8 сюжетных этапов), трофеи за ходьбу (1/2/5/10 км).
- **База:** 9 модулей с визуальной схемой, лимит уровня штабом, ночное перемирие
  (23:00–07:00), аварийный щит после отражённого рейда, перенос штаба за 300 кр.
- **Честность PvP:** щиты новичкам, лимит атак на зону, штраф за повторяемые
  атаки, перемирие ночью, сезонные сбросы (запланировано), приватность позиций.
- **Безопасность:** вода/дороги глушатся генератором, взаимодействия только
  в радиусе, предупреждения про реальную обстановку, приватные координаты не публикуются.
- **Античит (задел):** невозможные скорости отсекаются на входе
  (фильтр скачков >400 м/фикс), якорная привязка GPS, серверная валидация — на
  слое 3 мультиплеера.

## Известные ограничения MVP

- P2P-сигнализация ручная (коды копипастом) — нужен мессенджер рядом.
- Синхронизация last-write-wins: при конфликте захватов побеждает поздний.
- Нет общего персистентного мира между сессиями разных игроков (мир у каждого свой,
  синхронизируются события) — решается переходом на Supabase/Colyseus.
- AR — 2D-оверлей поверх камеры, не ARCore/ARKit (нужна нативная обёртка).
- Звук не реализован (концепт прописан: сервоприводы, радиообмен, тревоги).

## Что тестировать с живыми игроками в первую очередь

1. Длительность и сложность первых 3 боёв (кривая входа).
2. Темп экономики первого часа (успевают ли собрать 2-го меха).
3. Понятность обмена P2P-кодами (где теряются игроки).
4. Ценность энергии развёртывания: ограничение или раздражитель.
5. Мотивация к ежедневным/недельным целям после 3-й сессии.
